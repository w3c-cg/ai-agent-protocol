### III. Three proposals for the next protocol iteration

Gaowei presented [seven bilingual slides](materials/2026-09-23/W3C_AI_Agent_Protocol_Proposals_Bilingual_7_Slides_Revised.pptx) outlining three problems for community discussion, not a final protocol plan. He noted that the earlier Agent Identity proposal had been merged, while the following items need further design:

1. **Streaming HTTP authentication.** Authenticate stream setup separately from later content verification. For unknown-length streams, the complete body digest is unavailable at the start. The slides distinguish a baseline mode protected by HTTPS from an enhanced mode that signs a final digest for a finite stream. Expiry, reconnection, and downgrade behavior also need clear rules. A signed opening request establishes the initiator's identity but does not, by itself, prove the integrity of all later stream content.
2. **Mutual DID authentication.** Extend requester authentication with a server DID response proof. The proposed response signature would bind the response to the request, both participants' DIDs, and a fresh challenge, so the client can verify the expected server DID. HTTPS remains in place; it does not by itself prove control of the expected agent DID. Replay prevention and coverage of ordinary responses and stream setup remain design questions.
3. **DID plus OAuth authorization.** Keep authentication separate from authorization. DID identifies the acting agent and proves key control; OAuth could provide consent or policy, scope, and token lifetime. The group should explore how a DID-based agent maps to an OAuth client and accesses authorized resources, starting with roles and a minimal interoperable example rather than a new authorization protocol.

Song asked whether the proposed streaming HTTP authentication would appear in the imminent ANP open-source release. Gaowei clarified that it was **not included in that release** and was a direction for a later version. No final design or adoption decision for the three proposals was recorded.
